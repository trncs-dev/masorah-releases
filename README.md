# Masorah · מסורה

**Um mapa vivo do tempo judaico, da Torá, da tradição, da história e da vida judaica.**
*A living map of Jewish time, Torah, tradition, history and life.*

Este repositório contém apenas os **instaladores do Masorah para Windows** e o ficheiro de atualizações.
This repository holds only the **Masorah installers for Windows** and the update feed.

## Descarregar / Download

➡️ **[Última versão / Latest release](https://github.com/trncs-dev/masorah-releases/releases/latest)**: descarrega `Masorah-Setup-<versão>.exe` / download `Masorah-Setup-<version>.exe`.

- **PT:** Corre o instalador. Se o Windows SmartScreen avisar (o instalador ainda não tem assinatura digital), escolhe *Mais informações* → *Executar mesmo assim*. A partir da versão 0.6.0, o Masorah atualiza-se sozinho (Definições → Atualizações).
- **EN:** Run the installer. If Windows SmartScreen warns you (the installer is not code-signed yet), choose *More info* → *Run anyway*. From version 0.6.0 on, Masorah updates itself (Settings → Updates).

## O que é / What it is

Calendário judaico com o dia a começar ao pôr do sol, Shabat, zmanim, festividades, leituras da Torá, história do
povo judeu numa linha do tempo explorável, pessoas, lugares, mitzvot e vida judaica. Inclui uma biblioteca para ler
o Tanach, a Mishná e o Talmud Bavli, sem precisar de internet. Em português, inglês e hebraico. O Masorah não é um
posek: para questões práticas de halachá, pergunta ao teu rabino.

Jewish calendar with sunset-based days, Shabbat, zmanim, holidays, Torah readings, an explorable history of the
Jewish people, people, places, mitzvot and Jewish life. It includes a library for reading the Tanakh, Mishnah and
Talmud Bavli offline. In Portuguese, English and Hebrew. Masorah is not a posek: for practical halachic questions,
ask your rabbi.

## Privacidade / Privacy

[Política de privacidade / Privacy policy](https://gist.github.com/trncs-dev/e8a5d45ff2524665b8847cc67a1c7b97). There are no accounts, no telemetry and no advertising. The only connection Masorah makes on its own is the update check against this repository, and you can turn it off.

## Reportar um erro / Report an error

Em cada página do Masorah existe "Reportar um erro", que abre aqui uma [issue](https://github.com/trncs-dev/masorah-releases/issues) já preenchida.
Every page in Masorah has "Report an error", which opens a pre-filled [issue](https://github.com/trncs-dev/masorah-releases/issues) here.
